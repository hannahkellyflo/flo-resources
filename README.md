# flo-resources

Static resources hosted for Flo.

## legal-recruiting-tracker
Flo's public **Legal Recruiting Tracker** dashboard — a single self-contained `index.html`
(React, runtime, fonts, and data all inlined; no build step, no external requests).

Deploy on Vercel with **Root Directory = `legal-recruiting-tracker`** (Framework preset: *Other*).
To update: replace `legal-recruiting-tracker/index.html` and push — Vercel redeploys automatically.

> Note: data is a work-in-progress snapshot, not yet wired to live Metabase/Airtable.
